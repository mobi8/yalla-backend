# 01. 실제 데이터 인벤토리

조사일: 2026-11-16 (Asia/Dubai). 기준: 작업 트리의 실제 파일, HEAD `c8072e7`. 이미 존재한 Jackpot presentation 수정 및 Tools 백업은 보존했다. 분석은 정적 추적이며 Unity 실행·iOS 장치 검증·실제 사용자 저장 파일 열람은 하지 않았다. 이 문서의 Server/Shared는 **향후 권장 책임**, 현재는 로컬 코드가 권한을 가진다.

범위: 게임 의미를 가진 저장 schema, 경제/진행 config, Ranking DTO, 복원에 필요한 runtime projection. 이미지 좌표·애니메이션 duration·Unity 참조의 전체 필드 목록은 서버 데이터가 아니므로 제외한다. 결과 풀 500세트, 승패 결정, 물리 및 그 재설계는 제외하고 확정 결과 이후 정산 경계만 조사했다.

## 구현 상태와 저장 구분

- J: `Application.persistentDataPath/yalla-journey-player.json`, `YallaJourneyPlayerStore.Load/Save`. 모든 J 행은 JSON root 또는 명시된 parent 아래 저장한다. `.tmp/.bak`는 같은 schema이며 새 저장 키로 중복 계산하지 않는다.
- H: `save.dat`/`save.bak`, `HyperBase.Data.SaveManager`, AES 암호화 JSON. Bootstrap·Settings가 현재도 사용한다. 레거시 퍼즐 progression/경제는 Journey와 구분한다.
- P: PlayerPrefs `RateUs_Prompted` 하나. EditorPrefs는 개발 도구 상태이며 플레이어 저장과 다르다.
- Scene: Ranking 샘플은 `Assets/YallaDrop/Scenes/FiftyFiftyScene.unity:60027`의 snapshot. 실서버 순위가 아니다.
- Guest 원격 인증, Friends graph, Invite code/link, Apple/Google 계정 연결: 프로젝트 게임 코드에서 구현 확인 안 됨. ReferralWidgetView는 webshop WebView이며 초대 서비스가 아니다.
- Costume 보유/미리보기/장착/해제 구현. 실제 구매/일반 런타임 획득 함수 및 World costume 보상 pool은 없음. `GrantUncappedShield` 등 API만 있는 경로는 UI 구매 구현으로 간주하지 않는다.

## 표 해석

Data Category는 `주 유형 / 보조 유형`. 기본값은 신규 모델/실제 생성 경로 기준이며, receipt의 '생성 인수'는 신규 유저에게 해당 record가 없다는 뜻이다. JSON 누락/명시 null은 C# 선택 인수 default와 같다고 가정할 수 없다(03 참조). Trigger와 Owner가 합쳐 읽히도록 각 행에 명시했고, 자세한 필드 간 변경 조합은 02에 정리했다. Evidence 링크는 repository 상대 경로와 실제 선언 줄, Owner는 검색 가능한 실제 메서드명이다.

## 저장 키와 runtime projection 보충

| Data Name | Data Type | Current Location | Default Value | Data Category | Update Trigger | Update Owner | Related Data | Persistence | Server Authority | Migration Risk | Evidence |
|---|---|---|---|---|---|---|---|---|---|---|---|
| `RateUs_Prompted` | int | PlayerPrefs | 0 | State | review 요청/Editor reset | RateUsManager.RequestReview/ResetPromptedFlag | review eligibility | GetInt/SetInt/Save/DeleteKey | Client | 낮음; 경제 import 제외 | [RateUsManager.cs](../../Assets/YallaDrop/Core/HyperBase/StoreReview/RateUsManager.cs) |

`FiftyFiftySessionState`의 SessionId, EntryTierId, MinimumBet, CollectionTierId, StartingYallaPoint, YallaPoint, CurrentRound, Continuous는 저장 snapshot을 `StartNewSession`으로 복원하는 **복제 projection**이다. SessionActive/SessionCompleted, private roundInProgress/roundSettled는 런타임 gate다. `FiftyFiftyBettingController`의 EnergyBalance/HasLoadedPlayerData/EnergyRechargeRemainingSeconds/LockedEnergy/LockedPrediction/LastConfirmedRoundPayout/LastConfirmedRoundColor/CurrentMultiplier/dropRequested는 잔액·입력·표시 cache다. PendingEnergy/Prediction이 복원 기준이며 UI 선택값으로 덮지 않는다. 이들은 추가 영속 저장 키로 세지 않는다. `FiftyFiftyEntryContext`는 Scene 간 일회성 인계다.

`PlayerWallet.Water=5`, `PlayerWallet.Gold=1000`은 LegacySupport 정적 메모리 값이다. SpendWater/SpendGold/AddWater/AddGold가 변경하지만 SaveManager/Journey store 연결이 없고 재실행 시 복원하지 않는다. J Gold, H GoldBalance, YallaPoint와 같은 자산으로 간주하면 안 된다.

레거시 SO 보충: `BoostConfig` UndoGoldCost=500, ExtraEmptyTubeGoldCost=1200, DailyLoginBonusGold=50, GoldPerLevelMin=10/Max=50, DailyChallengeGold=100, StartingUndoCount=3, StartingExtraTubeCount=0. `DailyRewardConfig.Milestones[]` 항목은 StreakDay/GoldBonus/UndoBonus/ExtraEmptyTubeBonus/UnlocksSkin/SkinId/BadgeTitle이다. 후자의 skin metadata는 Journey Costume 획득과 연결되지 않는다. `LevelDatabase.asset`은 LevelData 참조 목록이며 레벨 완료 GoldReward/boost 플래그를 LevelManager가 읽는다. 이 레거시 catalog 세부 콘텐츠를 Journey 서버 config로 자동 활성화하지 않는다.

## 계수 기준과 결과

- J OptIn 선언 schema: **156개**, H PlayerData 저장 필드: **32개**, 합계 **188개 영속 JSON 필드 정의**. snapshot 2개 경로, 반복 receipt, 배열 원소는 정의당 1회 계산. root wrapper도 실제 JSON property이므로 포함.
- 주요 Config 명세 행: **60개**, Ranking Scene DTO: **8개**, PlayerPrefs: **1개**. 총 **257개 개별 표 행**. 보충 문단의 runtime 복제/legacy SO 필드는 이 수치에서 제외하므로 프로젝트 모든 C# 변수 개수라는 의미가 아니다.
- 사용자 저장 namespace **3개**: Journey JSON, HyperBase encrypted JSON, RateUs PlayerPrefs. 실제 파일명 5종: yalla-journey-player.json / .json.tmp / .json.bak / save.dat / save.bak. PlayerPrefs key 1개. RemoteConfig key 10개는 서버/SDK 설정 키이며 사용자 잔액 저장 키가 아니다.
